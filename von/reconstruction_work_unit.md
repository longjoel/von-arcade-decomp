## Completion

Mark exactly one:

- `modeled`: focused C model and test exist but are not linked into the image.
- `integrated`: the model is linked into the replacement image.
- `trace-validated`: the integrated model passes its runtime comparison.
- `byte-validated`: the generated bytes also match the bounded original range.
- `blocked`: evidence or hardware behavior prevents a safe translation.

Update `von/reconstruction_ledger.json` only after the evidence is captured.
